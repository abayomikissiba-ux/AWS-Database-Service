# AWS Database Services Assignment

## Overview

This project demonstrates the use of Amazon DynamoDB (NoSQL database) on AWS.

## Amazon DynamoDB Setup

### Table Details

* Table Name: Users
* Primary Key: userId (String)

## CRUD Operations

### 1. Create Item

* Added a new item into the table using the AWS console.
  
### 2. Read Item

* Retrieved item using the primary key (userId).

### 3. Update Item

* Modified an existing item by updating one of its attributes (e.g., age).

### 4. Delete Item

* Deleted an item from the table using the primary key.
